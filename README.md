# 이상한 바다의 나디아 — 메가드라이브 한국어 패치

메가드라이브판 「이상한 바다의 나디아」 일본판을 한국어로 즐기기 위한 패치입니다. 대사·메뉴·타이틀 한글화와 **챕터 자동 저장·이어하기**를 적용했으며, 오프닝 음악에 따라 두 가지 버전을 제공합니다.

현재 버전은 **SRAM34**입니다. 한국어 음악판은 **MD+ Lyrics V5**를 포함합니다. 전체 플레이 검수 중인 제작판입니다.

## 다운로드: 원하는 음악판 하나를 선택하세요

| 버전 | 다운로드 | 오프닝 음악 | 실행 방법 |
| --- | --- | --- | --- |
| **한글 음악판** | [한국어 주제곡판 ZIP](Nadia_Korean_Theme_SRAM34_V5_Patch.zip) | 한국어 주제곡과 한글 가사 10줄 | 동봉된 MD+ 실행기 사용 |
| **원본 BGM판** | [원본 BGM판 ZIP](Nadia_Original_Music_SRAM34_Patch.zip) | 원래 일본판 ROM의 게임 음악 유지 | 완성 ROM을 에뮬레이터에서 실행 |

**두 버전 모두 게임 대사와 메뉴는 한국어입니다.** 원본 BGM판이라는 이름은 음악을 원래대로 유지한다는 뜻입니다.

### 한글 음악판

한국어 오프닝 주제곡을 재생하며 가사 10줄을 표시합니다. 자막 전환 때 그림이 깨지는 문제를 수정한 V5 구성입니다. 게임 중 BGM은 원래 음악을 사용합니다.

ZIP에 음악판 IPS, `opening.wav`, ROM과 같은 이름의 `.cue`, MD+ 실행기와 설정 파일이 들어 있습니다. **IPS는 노래 재생 코드를 적용하며, 음원 자체는 외부 `opening.wav` 파일로 재생합니다.** IPS만 적용하고 음원·부속 파일을 빼면 한국어 노래를 들을 수 없습니다.

음악판에는 MD+ 지원 코어가 필요합니다. 동봉된 실행기는 `C:\RetroArch-Win64`의 RetroArch와 Genesis Plus GX 코어를 사용합니다. 모든 부속 파일을 완성 ROM과 같은 폴더에 두고 `START_NADIA_MDPLUS.cmd`로 실행하세요. 입력 없이 기다리면 실행 약 82초 후 한국어 노래가 시작되며, Start 버튼으로 오프닝을 건너뛸 수 있습니다.

### 원본 BGM판

원래 일본판 ROM에 들어 있는 오프닝과 게임 BGM을 유지합니다. `opening.wav`나 `.cue`가 필요하지 않으며, 완성 `.md` 파일을 Genesis Plus GX에서 열면 됩니다. 일본어 가창 음원을 추가한 버전은 아닙니다.

## 패스워드 방식에서 챕터 저장 방식으로 변경

원작은 패스워드를 기록한 뒤 다시 입력해 해당 장을 재개하는 방식입니다. 이번 패치는 **SRAM을 이용하는 챕터 자동 저장·이어하기**를 추가해 패스워드를 직접 기록하고 입력해야 하는 과정을 줄였습니다.

1. 새 챕터가 시작되면 해당 챕터가 자동으로 저장됩니다.
2. 다음 실행에서 **‘이어하기’**를 선택합니다.
3. 패스워드를 입력하지 않고 마지막으로 저장한 **챕터의 시작**부터 재개합니다.

저장 슬롯은 하나입니다. 저장 단위는 챕터이며, 챕터 안의 현재 위치·아이템·이벤트 진행을 저장하는 방식은 아닙니다. 챕터 도중 종료하면 다음 실행에서 그 챕터의 시작부터 다시 진행합니다. 에뮬레이터의 세이브스테이트 기능은 이 챕터 저장과 별개입니다.

기존 패스워드 기능도 유지했습니다. 저장이 없으면 패스워드 화면으로 들어가며, 저장이 있어도 **B 버튼을 누른 채 ‘이어하기’**를 선택하면 패스워드를 직접 입력할 수 있습니다. 패스워드 표시와 입력 문자판은 한글화했습니다. 이전 일본어 패스워드는 동봉된 `PASSWORD_TABLE.txt` 대응표로 입력할 수 있습니다.

‘처음부터’로 첫 챕터에 들어가면 기존 저장을 첫 챕터로 갱신합니다. 버전을 바꾸면서 저장을 옮길 때는 에뮬레이터 저장 폴더의 `.srm` 파일을 복사하고 새 ROM과 같은 이름으로 맞추세요.

## 패치 적용

이 저장소에는 원본 ROM과 완성 ROM이 포함되어 있지 않습니다. 일본판 원본 ROM이 필요합니다.

### 간편 적용

1. 원하는 버전의 ZIP을 다운로드하고 **모두 압축 해제**합니다.
2. 일본판 원본 ROM을 동봉된 **`PATCH_NADIA.cmd` 위로 끌어 놓습니다.**
3. 한글 음악판은 `output/music`, 원본 BGM판은 `output/normal`에 생성됩니다.
4. 한글 음악판은 생성된 폴더의 `START_NADIA_MDPLUS.cmd`, 원본 BGM판은 생성된 `.md`로 실행합니다.

Python 3가 필요하며 추가 Python 라이브러리는 필요하지 않습니다. 각 ZIP에는 해당 버전의 IPS 하나와 전용 설치 안내가 들어 있습니다.

### IPS를 직접 적용할 때

동봉된 `.ips`를 일본판 원본 ROM에 적용하세요. 두 패치를 서로 덧씌우거나 기존 한글 ROM에 적용하지 말고, 각각 원본 복사본에 적용합니다. 음악판은 완성 ROM 이름을 `Nadia_Korean_SRAM34_MDplus_Lyrics_V5.md`로 맞추고 동봉된 음악·실행 부속 파일을 옆에 복사해야 합니다.

```text
원본: Fushigi no Umi no Nadia (Japan).md
크기: 1,048,576바이트
SHA-256: 8281500efdb93ce6168e37921f774327bda0ea55e8682a5f7c123d72d59e6f9a
```

설치 도구는 원본과 패치·부속 파일, 완성 ROM의 해시 및 ROM 체크섬을 확인합니다. 원본 ROM을 수정하지 않으며 출력 위치에 다른 파일이 있으면 덮어쓰지 않습니다. ZIP의 해시는 [SHA256SUMS.txt](SHA256SUMS.txt)에 있습니다.

## 한글화 및 수정 내용

- 대사 번역 자료 2,967항목, 3,514페이지
- 행동·인물·대화·물품·지명 등 메뉴 한글화, 창 제목 중앙 정렬
- 타이틀·도입 문구·장 제목·게임 오버·사운드 메뉴 한글화
- NPC 물품·메모 등 아이템 입수 안내 28종과 ‘3개월 후…’ 문구 한글화
- 엔딩 그림과 대사 글꼴 충돌 수정, 제작진 역할명 한글화
- 패스워드 화면과 문자판 한글화, 챕터 자동 저장 추가
- 일본어 혼합 표기 수정, 반복 문구 20종을 48곳에서 통일

지정 화면의 글꼴·문자열 종료·창 닫기, 저장·패스워드 경로와 오프닝 음악·자막을 검사했습니다. 두 ZIP은 독립 폴더에서 원본에 적용하여 각 최신 ROM과 일치함을 확인했습니다. 번역 자료 수가 전체 장면의 플레이 검수 완료를 뜻하지는 않으며, 실제 전체 플레이 검수는 진행 중입니다.
